# 🌐 Internet Usage Analysis — Power BI

An interactive **Power BI dashboard analyzing global internet usage, adoption, and digital connectivity across approximately 80 countries**, with a dedicated focus on **Morocco compared with the global picture**.

The project transforms raw internet-usage data into an interactive analytical report designed to identify **digital adoption trends, country-level differences, and Morocco's position within the broader global landscape**.

> 🚨 **REAL-WORLD DATA:** This dashboard is built using real data covering approximately **80 countries**, allowing for meaningful cross-country comparisons rather than simulated examples.

---

## 📊 Dashboard Overview

The report provides an interactive view of internet usage across countries and enables users to explore:

* 🌍 Global internet usage and adoption
* 📈 Internet penetration and connectivity trends
* 🗺️ Country-level comparisons
* 🇲🇦 Morocco's internet usage compared with the global dataset
* 👥 Population and internet-user indicators
* 📅 Changes in internet usage over time
* 🔎 Geographic and demographic differences

The dashboard is designed to answer questions such as:

* Which countries have the highest levels of internet adoption?
* How has internet usage evolved over time?
* Where does Morocco stand compared with the global dataset?
* How different is Morocco's internet usage profile from the overall picture?
* Which countries show the largest gaps in digital connectivity?

---

## 🇲🇦 Morocco vs. Global View

A dedicated Morocco analysis provides additional context by comparing Morocco's indicators with the overall dataset.

This comparison helps highlight whether Morocco is:

* Above or below the global level for selected indicators
* Following similar or different internet adoption trends
* Experiencing faster or slower growth than the broader dataset
* Positioned differently depending on the metric being analyzed

Rather than looking at Morocco in isolation, the dashboard places its results within an international context.

---

## 💡 Key Insights

The dashboard allows several interesting patterns to emerge from the data, including:

* Significant differences in internet adoption between countries.
* A clear relationship between digital connectivity and development levels across many countries.
* Large variations in internet-user populations, meaning that adoption rate and absolute number of users can tell very different stories.
* Morocco's results become more meaningful when compared directly with the approximately 80-country dataset rather than viewed independently.
* The global map makes it possible to quickly identify geographic concentrations of higher and lower internet usage.

> **Important:** The dashboard is intended for exploratory and analytical purposes. Findings depend on the indicators, years, and countries selected in the dataset.
